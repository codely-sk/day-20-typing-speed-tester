# Day 20 — Typing Speed Tester ⌨️

A Python-based typing speed test application that measures typing speed, accuracy, errors, and time taken.

## ✨ Features

- Display randomly selected sentences for typing practice.
- Calculate typing speed in Words Per Minute (WPM).
- Measure typing accuracy as a percentage.
- Count incorrectly typed characters.
- Track the time taken to complete the test.
- Provide feedback based on typing accuracy.
- Interactive menu to start a test or exit the application.

## 🛠️ Technologies Used

- Python 3
- `time` module
- `random` module
- Functions
- Lists
- Loops and conditional statements
- String comparison
- Basic mathematical calculations

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python typing_speed_tester.py
```

5. Select **Start Test** from the menu.
6. Type the displayed sentence as quickly and accurately as possible.
7. View your typing speed, accuracy, errors, and completion time.

## 📊 How It Works

- A random sentence is selected from a predefined list.
- The program records the starting and ending time.
- The original sentence is compared with the typed sentence.
- Correct characters are counted.
- Typing speed and accuracy are calculated.
- Results are displayed after the test.

## 🧮 Calculations

**Words Per Minute (WPM):**

WPM = (Correct Characters / 5) / Time in Minutes

**Accuracy:**

Accuracy = (Correct Characters / Total Characters) × 100

## 📚 Learning Objectives

This project demonstrates how to work with Python's time and random modules, compare strings, count matching characters, calculate typing speed, and organize a program using functions.
